# LEGACY — Workforce Color Convention

**OBSOLETE. Do not load or use this convention.**

This file is preserved only for historical reference. The old convention mapped colors to `PREFERRED`, `AVAILABLE`, `CONFLICT` and `APPROVED` statuses.

The current Workforce rule is time-based shift classification:

- 05:00–11:59 — Sáng — yellow
- 12:00–16:59 — Trưa/chiều — red/pink
- 17:00–23:59 — Tối — cyan/teal
