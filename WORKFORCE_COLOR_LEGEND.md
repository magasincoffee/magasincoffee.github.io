# Workforce color convention

| Color | Meaning | Scope |
|---|---|---|
| Yellow | PREFERRED — employee prefers this shift | Employee registration/review |
| Cyan | AVAILABLE — employee is available for this shift | Employee registration/review |
| Red | CONFLICT — conflict or issue requiring review | Review/operations |
| Green | APPROVED — official approved schedule | Published/approved schedule |
| Gray | No registration / no data | Empty slots |

Registration cards must use the availability type from `employee_availability`.
Do not use color as a substitute for access scope or store identity.
