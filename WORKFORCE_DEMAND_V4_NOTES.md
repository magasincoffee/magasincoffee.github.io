# Workforce demand V4

This release rebuilds the staffing-demand board as a self-contained UI module.

- Weekly dates are derived locally from the selected Monday.
- Staffing demand is read from recurring templates and projected into the selected week.
- Owner can add a shift on each day independently.
- Time choices are 05:00–22:00 in 30-minute increments.
- Shift card colors are applied directly by start time: morning yellow, afternoon red, evening cyan.
- Existing Manager header/sidebar and other Workforce tabs are unchanged.
