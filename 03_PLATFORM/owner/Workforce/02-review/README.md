# 02 — Lịch đăng ký & Review

Single owner: `engine-v1.js`.

Responsibilities: branch selection, week navigation, employee registrations, edit time, branch-transfer request creation and transfer approval/rejection.

Rules:

- one store is reviewed at a time;
- current store is never offered as a transfer destination;
- transfer is a request first and only changes the employee's preferred store after approval;
- no old status-color legend;
- no transfer checkbox;
- no note field.
