# MAGASIN DOCUMENTATION

Đây là khu vực tài liệu chính thức của MAGASIN.

## Thứ tự đọc bắt buộc cho một phiên làm việc mới

1. `enterprise/MAGASIN_MASTER_OBJECTIVE.md`
2. `enterprise/MAGASIN_AI_CONTEXT.md`
3. `enterprise/MAGASIN_BOS_FRAMEWORK.md`
4. `enterprise/MAGASIN_WORKING_METHOD.md`
5. `enterprise/MAGASIN_WORK_CONTROL.md`
6. `enterprise/MAGASIN_DISCOVERY_PLAN.md`
7. `architecture/PROJECT_STRUCTURE.md`
8. tài liệu domain/module liên quan

## Nguyên tắc

Tài liệu được ưu tiên theo trạng thái đã xác nhận. Code không tự định nghĩa business rule.

## Trạng thái tài liệu

`DRAFT` → `PROPOSED` → `CONFIRMED` → `ACTIVE` → `SUPERSEDED`

## Cấu trúc

- `enterprise/` — mục tiêu, operating model, cách làm việc, AI context và kế hoạch phát triển.
- `architecture/` — cấu trúc kỹ thuật.
- `modules/` — quy tắc từng module.
