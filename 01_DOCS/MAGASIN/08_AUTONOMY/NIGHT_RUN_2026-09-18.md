## Power-loss recovery

The Windows bootstrap must be idempotent:

```text
Windows user logon
→ read AUTOSTART_DISABLED
→ start canonical GitHub Runner if offline
→ start installed Supervisor if offline
→ Supervisor opens dedicated Business OS Chrome
→ read repository source of truth
→ reconcile cursor/HEAD/CI
→ resume only unfinished safe work
```

Owner STOP is different from power loss:

- Owner STOP creates `AUTOSTART_DISABLED`;
- manual START clears it;
- crash/power loss does not create it;
- therefore crash/reboot auto-resumes, while an explicit Owner STOP stays stopped.

Chrome/ChatGPT automation requires a logged-in Windows desktop session. The robot must never bypass Windows PIN/password.
