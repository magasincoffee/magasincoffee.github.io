# 01 — Nhu cầu nhân sự

Single owner: `engine-v1.js`.

Responsibilities: store selection, week navigation, demand display, add/edit/delete shift, quantity validation and staffing-demand RPCs.

Display contract:

```text
09:00 – 17:00
Số lượng: 4 người    ✎
```

Edit mode exposes start time, end time and `Số lượng cần`, with Hủy / Lưu / Xóa.
